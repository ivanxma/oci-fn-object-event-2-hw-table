Replace incompatible database structures

This drops and recreates application-owned control and durable tables from the current external SQL files. Target data tables are not dropped, but mappings, captures, checkpoints, transaction logs, and archives are removed.

Stream user profile creation

Creates or rotates the stream user and grants ALL on the configured control, stream-data, and Resource Mapping target databases. The password is used once and never persisted.
